# 0.21.0

LibrarySync now supports the complete AIOStreams Watch State v2 surface.

- Explicit watched and unwatched marks override older playback/imported records.
- Resume positions, unfinished playback and released next episodes feed Continue Watching.
- Favourites, dropped shows and independent movie/show/season/episode ratings round-trip.
- Season/show bulk marks use a durable inbox with per-episode outcomes and retry support.
- Household viewers require invitation acceptance and keep separate user state.
- The addon page adds resume and rating controls, viewer consent, sync diagnostics and mapping repair.
- Unchanged pulls reuse database-invalidated snapshots without scanning history or next episodes.
- Original absolute episode identities survive mapping; canonical numbers are used at provider boundaries.
- Reused playback position IDs are distinguished by their immutable event timestamps.
- Superseded rating deliveries, including queued history ratings, cannot overwrite independent state.

The AIOStreams proxy importer and its configuration UI have been removed. Migration
`8e9f0a1b2c3d` preserves imported history, retires proxy integrations, deletes their secrets,
and removes obsolete import queue entries. It adds Watch State inbox, projection, consent,
revision and snapshot tables. A downgrade preserves history but cannot recover deleted proxy credentials.

After updating, refresh the LibrarySync addon in AIOStreams and select its Watch State resource.
Watch State remains opt-in. Workers using `all` already include inbox processing; custom modes
must include `watch_state`, or run the dedicated scaled worker.

The shared external episode-identity refactor is deferred. See the README for rating-provider
capabilities and `docs/watch-state-testing.md` for local conformance testing.

Validation: 397 backend tests passed with PostgreSQL concurrency and migration checks enabled.
Two live conformance tests passed against unmodified AIOStreams 2.35.9 using AIOMetadata and
an upstream AIOStreams stream addon, restricted so the older nested LibrarySync tracker was
excluded. Browser checks covered decimal rating save/clear, viewer invitation/acceptance/revocation,
resume removal and episode mapping repair. Ruff, JavaScript syntax, CSS build and Compose validation passed.
Downstream provider delivery was verified with connector contract tests; no production tracker accounts were modified.
