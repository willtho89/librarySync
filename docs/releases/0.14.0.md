# librarySync 0.14.0

Released: 2026-03-17

This release covers changes from `0.13.2` to `0.14.0`.

## Highlights

- Fixed Stremio series removals so outbox delivery no longer retries or fails when Cinemeta returns no episodes for the target series.
- Added regression coverage for the Stremio outbox removal path.
- Added dashboard stats test coverage to lock in empty-state and populated response behavior.

## Runtime and Development Changes

- Raised the backend Python requirement to `>=3.13`.
- Added a `tests` optional dependency with `pytest`.
- Updated development documentation to use `uv sync --extra tests`, `ruff`, and `pytest`.
- Expanded documented worker mode options to include `metadata_backfill`, `merge_history`, and `merge_all_history`.

## CI and Publishing

- CI now runs linting and tests on Python `3.13` and `3.14`.
- CI linting now covers both `backend/src` and `backend/tests`.
- Publishing workflow Docker actions were refreshed to current major versions.

## Notes

- No database migrations were added in this release window.
